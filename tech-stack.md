# Tech Stack

## Frontend
- HTML
- CSS
- JavaScript

## Backend
- Python
- Flask
- Flask-CORS

## AI Layer
- Gemini API
- OpenAI-compatible Gemini endpoint

## Deployment
- GitHub
- Vercel (Frontend)
- Hugging Face Spaces (Backend)

## Why This Stack?

This stack was chosen to build a fast, lightweight, and working AI-powered prototype.

- **HTML, CSS, and JavaScript** were used for a simple and accessible frontend.
- **Python Flask** was used to create a lightweight backend for handling requests and AI integration.
- **Flask-CORS** was added to allow frontend-backend communication across deployments.
- **Gemini API** was used as the core intelligence layer for profile evaluation and personalized feedback generation.
- **Vercel** was used to deploy the frontend quickly and reliably.
- **Hugging Face Spaces** was used to host the backend and make the AI analysis available online.
- **GitHub** was used for version control, documentation, and project delivery.
