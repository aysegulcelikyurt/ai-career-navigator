# Tech Stack

## Frontend
- HTML
- CSS
- JavaScript

## AI Layer
- Gemini API (planned integration)

## Deployment
- GitHub
- Lovable or Netlify

## Why This Stack?
Bu teknoloji seçimi, hızlı ve basit bir prototip geliştirmek için uygundur. HTML, CSS ve JavaScript ile kullanıcı dostu bir arayüz oluşturulabilir. Gemini API ise yapay zeka analiz katmanını sağlamak için planlanmıştır. GitHub proje yönetimi için, Lovable veya Netlify ise uygulamayı yayınlamak için kullanılacaktır.
