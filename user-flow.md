# 🔄 User Flow

## 1. User Input

- User opens the AI Career Navigator web app
- Enters:
  - Department
  - Target role
  - Target company
- Selects application stage (before / interview / rejected)
- Uploads CV or writes a summary
- Optionally explains past rejection experience

---

## 2. AI Processing

The system processes the input using AI:

- Analyzes CV content and user background
- Compares profile with target role requirements
- Identifies skill gaps and strengths
- Evaluates competitiveness level

---

## 3. Output Generation

The AI generates a structured response:

- 🎯 Competitiveness Score (0–100)
- 🧠 Personalized Verdict
- 💪 Strengths
- ⚠️ Gaps
- 📅 30-Day Improvement Plan

---

## 4. User Action

- User reviews insights
- Understands weaknesses and opportunities
- Follows the suggested roadmap
- Improves future applications

---

## 🔁 Continuous Improvement Loop

User can re-run the analysis after improving their profile, creating a feedback loop for continuous growth.
