# User Flow

1. The user opens AI Career Mentor.
2. The user enters their department, target role, and company name.
3. The user selects the application stage.
4. The user uploads a CV file or pastes a CV summary.
5. The user optionally explains a rejection or interview experience.
6. The user clicks the analysis button.
7. The system shows:
   - CV Match Insight
   - Missing Skills
   - Company Preparation
   - Interview Readiness
   - Possible Rejection Reasons
   - Suggested Next Steps
   - Sample Application Message
8. The user applies the recommendations to improve future applications and interviews.
